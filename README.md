# Automation Testing For Todo List Application

This repository contains automated tests for the [Todo List Application](https://todo-list-six-umber-66.vercel.app/). The test scenarios and documentation are based on the specifications found in this repository: [muhnatha/TodoList](https://github.com/muhnatha/TodoList).

## Overview

The goal of this project is to automate the testing process for the Todo List web application to ensure reliability and correctness of features such as adding, editing, and deleting tasks.

## Target Application

- **URL:** [https://todo-list-six-umber-66.vercel.app/](https://todo-list-six-umber-66.vercel.app/)

## Prerequisites

To run these tests locally, ensure you have the following installed:

*   [Python](https://www.python.org/) (version 3.11 or higher recommended)
*   [Selenium](https://www.selenium.dev/)
*   [ChromeDriver](https://sites.google.com/chromium.org/driver/) (version 142 or same with your chrome version)

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/lituldust/qa-automation.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd qa-automation
    ```
3.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Running Tests

To execute the test suite, run the following command:

```bash
python signup-automation.py
```
